# 📦 우편 소포 물량 예측 기반 배차 최적화

> 2026 물류데이터 AI 활용 및 분석 아이디어 공모전 출품작

우정사업본부 공개 소포 데이터로 **시도 간 소포 물량을 하루 단위로 예측**하고,
그 예측을 바탕으로 **직송할지 / 다른 출발지로 모아서 보낼지와 트럭 조합을 결정해 운송비를 줄이는** 2단계 파이프라인입니다.

## 주요 결과

| 구분 | 내용 |
|---|---|
| 물량 예측 (테스트 기간 2026.06) | LSTM WAPE **12.66%** · LightGBM WAPE 18.07% |
| 앙상블 | 검증셋 기준 최적 가중치 LSTM 1.00 → LSTM 단독 사용 |
| 배차 최적화 (예측 물량 기준) | 전부 직송 대비 운송비 **4.74% 절감** |
| 배차 최적화 (실제 물량 기준) | 5.08% 절감 → 예측만으로 이상적 절감 효과의 약 93% 달성 |

> ⚠️ 운송 단가는 공개되지 않아 국토교통부 화물자동차 안전운송원가 등을 참고한 **가정치**를 사용했습니다. 절감률의 절대값보다 "어떤 조건에서 모아서 보내기가 유리한가"라는 구조가 핵심 결과입니다.

## 파이프라인

```
① 데이터 준비       ② 물량 예측            ③ 배차 최적화              ④ 효과 측정
data.py       →    lstm.py / lgbm.py  →   dispatch.py          →   integration.py
                   models.py
소포 원본 →         노선별·일별 무게 예측    직송 vs 모아서 보내기 결정     전부 직송 대비
노선별 일별 집계     (LSTM / LightGBM)       + 트럭 톤급 조합 최적화        절감률 계산
```

1. **데이터 준비** — 소포 접수 기록을 (날짜, 출발 시도, 도착 시도)별 하루 총중량으로 집계하고, 요일·공휴일 피처와 lag·rolling 피처를 생성합니다. 육로 운송이 불가능한 제주는 제외했습니다.
2. **물량 예측** — 범주형 임베딩 + LSTM(과거 14일 입력)과 LightGBM을 학습하고, 검증셋에서 두 모델의 앙상블 가중치를 탐색합니다.
3. **배차 최적화**
   - 각 구간의 트럭 조합(1~25톤, 10종)은 OR-Tools CP-SAT 정수계획법으로 최소 비용을 계산합니다.
   - 같은 목적지로 가는 출발지들 중 어느 물량을 어디로 모을지는 탐욕(Greedy) 알고리즘으로 결정합니다.
   - 지역 간 거리는 카카오모빌리티 길찾기 API로 구한 우편집중국 간 실제 도로거리를 사용합니다.
4. **효과 측정** — 날짜×목적지별 결과를 모아 전부 직송했을 때와 비용을 비교합니다.

## 한계와 개선 방향

- 운송 단가가 가정치이며, 비용 가정에 대한 민감도 분석이 필요합니다.
- 탐욕 알고리즘은 전역 최적해를 보장하지 않습니다.
- 예측 물량으로 정한 배차를 실제 물량에 적용했을 때의 비용(트럭 부족 등)은 반영하지 않았습니다.
- LSTM은 앞 14일이 필요해 테스트 기간 앞부분이 평가에서 빠집니다.
- 공간 단위가 시도 수준이라 같은 시도 안의 거리 차이를 반영하지 못합니다.
